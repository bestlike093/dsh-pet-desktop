# 设置页信息架构重整（2026-11-02）

> 目标：把「按技术模块堆设置」改成「按用户想做的事找设置」。
> 一级导航从 9 项收到 5 项；同一件事不再分散在三个页面。
> 本方案不改设置字段名、不改既有 DOM id、不新增 IPC。

---

## 一、现状诊断（按当前 `settings.html` 实测）

### 1.1 导航碎片化

当前 9 个导航项：

| 导航 | 包含内容 | 问题 |
| --- | --- | --- |
| 通用 | 外观、立绘、角色尺寸、窗口、气泡、素材包、HUD 叠层 | 7 节堆一页，找 HUD 要滚到底 |
| 陪伴 | 主动台词、夜间不扰、陪伴任务、情绪与反思 | 相对完整 |
| 记忆 | 记忆 | 单节，导航权重过高 |
| 连接 | 连接、余额 | API Key 与余额混在一起 |
| 聊天 | 聊天 | 单节 |
| 语音 | 语音 | 单节 |
| 语言 | 语言 | 单节 |
| 人格 | 人格 | 单节 |
| 能力 | 模块、能力中心、未开放 | 未开放项只占一小块 |
| 运行状态 | 运行状态 | 单节，和「数据与备份」割裂 |
| 数据与备份 | 加密备份、同步、聊天记录 | 相对完整 |

「连接 / 聊天 / 语音 / 语言 / 人格」五个页面各自只有 1 节，用户为了改一个语音参数，要先在五个近义导航里猜。

### 1.2 页面内没有「先做什么」

- 没有页头说明这一页在管什么。
- 没有当前状态摘要（已连接 / 未配置 / 本地语音未启动）。
- 空状态只说「还没有导入模型」，没有下一步按钮或格式说明。

### 1.3 搜索能用，但不够顺

- 搜索会跨面板过滤，并自动切到第一个命中面板（`settings.js:287-331`）。
- 命中项在折叠的 `<details>` 里时不会自动展开，用户可能看不到。
- 命中后没有滚动与高亮。
- 无结果时只把计数改成「无结果」，没有空状态卡片。
- `Esc` 清空搜索、`Ctrl+F` 聚焦搜索已经实现（`settings.js:2087-2101`）。SSOT #12 仍标未做，属于漂移，封版前先核对。

### 1.4 未开放项没有统一语义

- 只有能力页有一块 `section.pending`。
- 其他页面若有未开放入口，看起来仍像可用。
- 没有统一的「内测未开放」徽标、原因、不可交互样式。

## 二、新信息架构

一级导航 6 项，按「她在哪、怎么说话、怎么陪、记得什么、能做什么、数据在哪」组织。

```
她          她是谁、长什么样、怎么待在桌面上
对话        她用什么模型、怎么说话、声音、语言
陪伴        她什么时候主动出现、陪伴任务、情绪
记忆        她记得什么、怎么导出
系统        能力开关、能力面板、备份、同步、状态
```

### 2.1 页面与子标签

| 一级页 | 子标签 / 页内分组 | 对应旧 panel |
| --- | --- | --- |
| 她 | 样子（外观、立绘、尺寸与窗口、气泡、素材、HUD 锚点 chips）、人格 | `general` / `persona` |
| 对话 | 模型、聊天、语音、语言 | `connection` / `chat` / `voice` / `language` |
| 陪伴 | 主动出现、夜间不扰、陪伴任务、情绪与反思（页内分组） | `companion` |
| 记忆 | 单页 | `memory` |
| 系统 | 能力、备份与同步、运行状态 | `ability` / `data` / `status` |

### 2.2 为什么这样合

- 人格和外观、立绘都回答「她是谁」，放在「她」里。
- 「模型 / 聊天 / 语音 / 语言」都是「她怎么和你说话」，放在「对话」里，用户不用猜。
- 「余额」跟着「模型」走，因为余额就是模型账户的余额，不单独占一级。
- 「记忆」保持独立，因为它是用户最在意、也最需要解释规则的一页。
- 「能力 / 备份 / 状态」都是「应用层面怎么管」，合成「系统」。

### 2.3 「模块」和「能力中心」的命名

现在这两块容易混，实际职责不同：

| 现名 | 实际是什么 | 新位置 | 建议名 |
| --- | --- | --- | --- |
| 模块 | 气泡、提醒两个开关，写入 `settings.modules`，控制下次启动是否 bootstrap | 系统 / 能力 | 内置模块 |
| 能力中心 | 一个按钮，打开独立窗口，里面有猜拳、素材库、记忆、语音、余额、巡视、反思 | 系统 / 能力 | 能力面板 |

「模块」是开关，「能力面板」是入口。新页面里分两块写，不再让两个近义词并排。

内测版不给能力面板加总开关，入口下方加一行小字：

> 内测版先不设总开关，点开就是当前已接通的能力。

等以后有「是否在桌宠上显示能力入口」的消费方，再补真开关。

## 三、实现策略（低风险迁移）

### 3.1 保留旧 panel，新增 page 容器

不重写设置项，只重排 DOM：

```html
<div class="page" data-page="talk">
  <div class="subnav" role="tablist">
    <button data-panel="connection" class="active">模型</button>
    <button data-panel="chat">聊天</button>
    <button data-panel="voice">语音</button>
    <button data-panel="language">语言</button>
  </div>
  <div class="panel active" data-panel="connection">...</div>
  <div class="panel" data-panel="chat">...</div>
  ...
</div>
```

- 保留 `.panel`、`section`、`data-panel` 值和所有 DOM id。
- 新增 `.page` 只负责分组显示；`showPanel(name)` 在切 panel 后同步切父 `.page`。
- 导航按钮从 `data-panel` 改为 `data-page`，高亮按 page；子标签按钮仍用 `data-panel`，复用现有切换函数。
- 搜索仍遍历 `.panel`，命中后调用 `showPanel`，并同步子标签 active 状态。

### 3.2 「她」页两个子标签

- **样子**：`general`，顶部加锚点 chips：外观 · 立绘 · 尺寸与窗口 · 气泡 · 素材包 · HUD。
- **人格**：`persona`。

chips 点击滚动到对应 `section` 并高亮 1.2 秒，不隐藏其他内容。这样既缩短寻找路径，也不破坏搜索过滤和现有 `details` 分组。

### 3.3 「陪伴」「系统」用页内分组

「陪伴」内容不多，保留 `section` 顺序，加页内小标题与锚点即可。「系统」用三个子标签：能力、备份与同步、运行状态。

## 四、人性化规则

### 4.1 页头

每个一级页顶部统一：

```html
<header class="page-head">
  <div>
    <h2>对话</h2>
    <p>她用什么模型、怎么说话、声音像谁</p>
  </div>
  <span class="save-state" data-state="saved">已保存</span>
</header>
```

保存状态四态：

| 状态 | 文案 | 触发 |
| --- | --- | --- |
| `saved` | 已保存 | 写盘成功 |
| `dirty` | 有未提交的修改 | 输入变化、尚未失焦 |
| `saving` | 保存中… | 写盘请求发出 |
| `failed` | 保存失败，点此重试 | 写盘失败 |

现有 `saved-tip` / `pending-tip` 已覆盖一部分，补齐四态与失败重试即可，不新建状态机。

### 4.2 空状态

每个空状态必须包含「为什么空」+「下一步做什么」。

| 位置 | 空状态文案 | 下一步 |
| --- | --- | --- |
| 立绘 | 还没有立绘 | 「导入压缩包」「导入文件夹」+ 支持格式说明 |
| 模型连接 | 还没有连接模型 | Key 输入框 + 「去 DeepSeek 申请」链接 + 「测试连接」 |
| 语音 | 本地语音服务未启动 | 状态点 + 「启动服务」+ 「查看日志」 |
| 同步 | 还没有配置同步 | 「先设置备份密码」 |
| 记忆 | 还没有记忆 | 「聊几句后会自动出现」 |
| 搜索 | 没有找到「xxx」 | 「清除搜索」 |

### 4.3 搜索增强

- 命中项在 `<details>` 内时自动 `open`。
- 命中项 `scrollIntoView({ block: 'center' })`，加 `.is-search-hit` 高亮 1.5 秒。
- 无结果时显示空状态卡片，不再只改计数。
- 搜索框右侧加「清除」按钮，`Esc` 仍可用。
- 搜索命中后，导航高亮到所属一级页，子标签切到命中 panel。

### 4.4 重置与危险操作

- 「恢复默认」按子标签 / section 分组，不整页一键重置。
- 重置前二次确认，写明会恢复哪些项。
- 删除记忆、删除素材包、恢复备份、清空聊天记录：二次确认 + 影响说明 + 不可撤销提示。
- 危险按钮使用 `danger` 样式，不和「保存」并排。

### 4.5 导航

- 6 个一级项，左侧固定，不滚动。
- 当前页高亮；子标签横向排列，超出可横向滚动。
- 导航项不显示未读数或红点，避免制造焦虑。
- 底部保留版本号与「打开日志目录」，不放进一级导航。

## 五、未开放项统一锁定态

### 5.1 视觉与交互

```html
<div class="item beta-locked" aria-disabled="true">
  <div class="item-text">
    <div class="item-label">
      低额告警
      <span class="badge-locked">内测未开放</span>
    </div>
    <div class="item-hint">判定与去重还在接线；本版只展示 7 天余额。</div>
  </div>
  <span class="lock-mark">—</span>
</div>
```

- 容器 `opacity: .55`，控件 `pointer-events: none`。
- 控件加 `tabindex="-1"`、`aria-disabled="true"`。
- **不写 `disabled` 属性**，保持 SSOT #36「全页无 disabled」的事实不漂移。
- 不隐藏。隐藏会让测试者以为功能不存在；变黑能明确边界。

### 5.2 集中清单

「能力」页底部固定「内测未开放」分组，逐项一行：

| 项 | 原因 |
| --- | --- |
| 余额低额告警 | 判定与 ack 还在接线，本版只展示 7 天余额 |
| QQ 唤醒 | 只有通道契约，没有消息入口 |
| 作息机制 | 只有重试退避，没有时段策略 |
| 云端语音 | 只有本地合成，计费轨未接 |
| Safe 陪伴版 | 单一产物，未做分发分支 |
| 远程拍板 | 只有三个通道，没有 dry-run 与回填 |
| 游戏真实执行 | 模拟输入有账号封禁风险，需要单独授权 |

原页面若还有残留入口，也标同一锁定态，避免「两个地方说法不一致」。
