## 三、55 记忆衰减：最小实现

### 目标

把 `memory.mjs:182` 的裸 FIFO 换成「按时间衰减 + 保留最近上下文」的裁剪，不引入新的存储格式版本，旧记忆能直接读。

### 方案

- 每条记录补 `weight`（0–1），读取旧记录时按 `at` 补算；没有 `at` 的记 1。
- 衰减公式：`weight = 0.5 ** (ageDays / 14)`，半衰期 14 天。
- 裁剪顺序：超过 `maxItems` 时，从权重最低的开始淘汰；**最近 20 条永不淘汰**，保证当前对话上下文完整。
- 用户消息与助手消息同权，不按角色加权，避免「她记得自己说过什么、不记得你说过什么」这种偏差。
- 落盘继续走 `seal`；`weight` 只存在密文里，导出时带上，同步包按现有白名单处理。
- 设置页记忆区加一行说明：「更早的对话会逐渐变轻，最近 20 条始终保留。」不做开关，避免新增假设置。

### 验收

- 构造 600 条、跨 60 天的记录：30 天前的低权重先被裁，最近 20 条保留。
- 旧版无 `weight` 的记忆文件能读、能写、能导出。
- `memory.test.mjs` 覆盖：衰减公式、最近 20 条保护、空 `at`、导出字段。
- 不触碰 `seal/open` 接口与文件格式版本。

## 四、61 游戏日常：内测边界

### 已有

`packages/core/src/game/` 已有排班校验（`dailySchedule.ts`）、武装阶梯（`clientControl.ts`）、安装检测（`dependencyCheck.ts`）、看护（`watchdog.ts`）、日报与 RPS，单测齐全。

### 内测只补三件事

1. **设置页入口**：能力页新增「游戏日常（内测）」卡片，检测 BetterGI 路径与版本，显示「已找到 / 未找到 + 去下载」。
2. **排班 dry-run**：复用 `validateConfig` / `toTaskSpec`，保存后只生成规格预览，不注册计划任务、不启动进程。
3. **风险明示**：卡片顶部固定一段说明——真实操作会模拟点击/按键，可能被游戏判定为第三方工具，最坏封号；内测不开放真实模式。

### 不做的

- 不接 `real` 模式执行器。
- 不写 Windows 计划任务。
- 不启动 BetterGI 进程。
- 不把「武装阶梯」暴露成可点按钮；它留在代码层，等真实执行立项时再接 UI。

### 验收

- 未安装 BetterGI：显示安装提示，保存排班仍可用（dry-run）。
- 非法时间 / 超时 / 游戏类型：一次性列出全部错误。
- dry-run 只返回 `TaskSpec`，无进程、无文件、无计划任务副作用。
- 设置页真实模式控件为锁定态，点击无反应，旁边写明原因。

## 五、设置页整改（封版前必做）

### 5.1 统一「变黑」语义

新增一个锁定态，不再让未完成项看起来能用：

- 容器加 `beta-locked`，标题与说明降为 `--muted`，控件 `pointer-events: none`、`tabindex="-1"`、`aria-disabled="true"`。
- 标题右侧加 `badge-locked`：「内测未开放」。
- 说明行写清原因与替代路径，例如「低额告警还在接线，本版只展示 7 天余额」。
- **不隐藏**这些项。隐藏会让测试者以为功能不存在，变黑能明确边界。
- 为保持 SSOT #36「全页无 `disabled`」的事实不漂移，锁定态用 `aria-disabled` 与指针事件，不写 `disabled` 属性。

### 5.2 未开放项集中到能力页

能力页新增「内测未开放」分组，逐项列出：余额告警、QQ 唤醒、作息、云端语音、Safe 版、远程拍板、游戏真实执行。每项一行原因，不放可点控件。

### 5.3 人性化清单（按优先级）

| 优先级 | 改动 | 理由 |
| --- | --- | --- |
| P0 | 未开放项统一变黑 + 原因 + 徽标 | 内测第一原则：不放假开关 |
| P0 | 空状态给下一步：未导入立绘、未填 Key、未配语音、未配同步 | 新用户不知道下一步 |
| P0 | 保存状态常驻：已保存 / 写盘失败 / 有未提交 | 现有 `saved-tip` / `pending-tip` 已有一半，补齐文案 |
| P1 | 分段「恢复默认」加确认 | SSOT #13 仍未收口 |
| P1 | 搜索无结果空状态 + 清除按钮 | 搜索已存在，缺反馈 |
| P1 | Esc 关窗、Ctrl+F 聚焦搜索 | SSOT #12 的一半 |
| P1 | 记忆页加衰减说明与「最近 20 条保留」 | 55 落地后必须解释 |
| P1 | 余额页加 7 天切片小表 | 58a 已有数据，别只显示一个数 |
| P2 | 游戏日常卡片：检测、排班、dry-run、风险说明 | 61 内测入口 |
| P2 | 通用页「缩放」补实际像素读数 | SSOT #30 |
| P2 | 聊天窗与开关轨道收 token | SSOT #31/#32/#33，视觉一致性 |

## 九、风险

- **61 真实执行**：模拟输入可能触发账号封禁，内测不开放。若以后要做，必须先走 `clientControl` 的三次警告 + 30 分钟时限，并单独发风险确认。
- **55 记忆衰减**：用户可能感觉「记忆变少了」。设置页必须写清规则，导出保留完整记录。
- **设置页改动面大**：只动容器与样式，不改字段名与 DOM id；每批改动后跑 `settings` 相关测试与手动冒烟。
- **SSOT 漂移**：封版前先核对，避免把已完成的项当缺口重复做。
- **内测包无签名**：当前 `win.target: dir`，直接发压缩包；不承诺安装器体验。
